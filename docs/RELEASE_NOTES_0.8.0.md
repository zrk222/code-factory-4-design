# Prestige 0.8.0

Prestige 0.8.0 adds proof-carrying seven-lens interface critique.

- `prestige critique` emits `prestige.critique.v1` receipts.
- Deterministic and heuristic findings are separated.
- P1/P2/P3 priorities use Observation / Problem / Fix guidance.
- Contrast, accessible names, focus state, target size, density, typography,
  and DESIGN.md drift have executable source checks.
- DESIGN.md, MOOD.md, and VOICE.md are hash-bound or explicitly missing.
- A seven-mutant challenge proves the critique instrument is non-hollow.
- The MIT-derived taxonomy is pinned and attributed in NOTICE and docs.

The critique does not claim browser-rendered fidelity, accessibility
conformance, conversion lift, or brand fidelity without project evidence.
